# タカクラのアプリ一覧

授業や日々の仕事に使えるブラウザアプリをまとめています。

**[アプリ一覧を開く](https://ken-tak-steam.github.io/apps/)**

## 使い方

一覧から使いたいアプリを選んでください。

- **「今すぐ使う」**：ブラウザでアプリを開きます。
- **「ダウンロード」**：HTMLファイルの保存案内を開きます。
- **「GitHubリンク」**：アプリの説明やソースコードを確認できます。

ダウンロード案内がないアプリは、「HTMLを取得（GitHub）」から取得ページへ進めます。GitHubの「Download raw file」を使ってHTMLを保存してください。

## 利用上の注意

- 対応端末・ブラウザ、使い方、利用条件は、各アプリの案内をご確認ください。
- インターネット接続が必要なアプリもあります。ダウンロード後のオフライン利用に対応するかは、各アプリの説明をご確認ください。
- 編集に使う元のファイルは残し、保存した結果を確認してからご利用ください。
- 一覧は定期的に更新されます。新しいアプリの反映まで時間がかかる場合があります。

この一覧ページには、アクセス解析や外部フォントの読み込みはありません。各アプリの通信については、それぞれの案内をご確認ください。
